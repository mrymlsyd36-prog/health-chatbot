# HealthCare Assistant Pro 🩺

An intelligent healthcare management and diagnostic support system built with Python and Streamlit.

## 🚀 Features
* **AI Health Chatbot:** Interactive symptom analysis and smart medical guidance.
* **Smart Medical Analysis:** PDF report reading and advanced medical imaging OCR.
* **Doctor Booking System:** Instant appointment booking with specialists.
* **Patient Portal:** Complete medical management and prescription tracking.

## 🛠️ Tech Stack
* **Language:** Python
* **Web Framework:** Streamlit
* **Libraries:** Pandas, Streamlit components, Image processing tools.

## How to Run
pip install -r requirements.txt
streamlit run app.py
